# Day 1 - Task 2: NumPy Vector Calculations

Performed linear algebra transformations, dot products, and multi-dimensional array operations using NumPy in a Jupyter Notebook.

## What was done
- Vector operations: dot product, cross product, and magnitude
- Multi-dimensional arrays: 2D and 3D array creation, reshaping, element-wise operations, and axis-wise sums
- Matrix operations: multiplication, transpose, determinant, inverse, and eigenvalues
- Linear transformations: 2D rotation and scaling matrices
- Solving a system of linear equations with `np.linalg.solve`

## Environment
- Python 3.11
- Conda environment: `env1`
- Libraries: NumPy, JupyterLab, pandas
